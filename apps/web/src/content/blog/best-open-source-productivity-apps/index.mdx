## How to judge an open source productivity app

A public repo is not enough. Before you trust an app with your tasks or notes, check these six things. Each card below shows most of them.

1. **License.** Open the LICENSE file. MIT, Apache, GPL and AGPL are open source. "Source-available" or "fair-use" licenses limit how you can use the code.
2. **Release cadence.** Look for a release in the last six months. Long gaps are a warning sign.
3. **Last commit.** Recent commits show someone still fixes bugs. Read the README too, since some projects say they are in maintenance mode.
4. **Self-hosting.** A Docker image and clear docs mean you can move the app to your own server later.
5. **API and MCP.** An API lets you export your data and connect other tools. An MCP server lets AI agents like Claude or ChatGPT use the app.
6. **Mobile.** Many open source apps have no phone app. Check whether you get a real app, a web app you can pin, or nothing.

## What counts as open source?

Open source means the code is public and the license lets you use, change and share it. Not every public repo meets that bar. The license tells you what you can really do.

| License | Self-host | Change and share | Commercial use |
|---|---|---|---|
| **MIT, Apache 2.0** | Yes | Yes | Yes |
| **GPL-3.0, AGPL-3.0** | Yes | Yes, but share your changes | Yes |
| **Non-commercial (Open Sunsama)** | Yes, for personal use | Personal use | Needs a commercial license |
| **Source-available (Anytype, PLANKA)** | Yes | Limited | Limited |
| **Closed source (Obsidian)** | No code to host | No | Yes |

Here is Open Sunsama's license in plain words.

The code is public on GitHub. It uses a non-commercial license: you can read it, run it and self-host it for personal use. Companies need a commercial license.

That is not an OSI license. If your company needs MIT or GPL, pick Super Productivity for planning and Vikunja or tududi for tasks.

We left out three well-known apps on purpose. Obsidian is closed source. Anytype and PLANKA publish their code under source-available licenses, not open source ones.

## Task management apps

<OssApp id="vikunja" rank={3} bestFor="People and small teams who want Todoist-style lists plus kanban, Gantt and table views on their own server." />

- **Falls short:** no native phone app, just a web app you pin to your home screen. No calendar view for time blocking.

<OssApp id="tasks-org" rank={5} bestFor="Android users who want their tasks synced with their own CalDAV server." />

## Which open source productivity apps work with AI agents?

MCP is the plug that lets an AI agent read and change your tasks. In 2026 it matters as much as an API.

- **Open Sunsama:** a hosted MCP server with OAuth sign-in and 24 tools. It works in Claude, ChatGPT, Cursor and any MCP client, and it reads your synced meetings too. See the [MCP setup guide](/docs/mcp/overview).
- **tududi:** an MCP server built into the app.
- **Joplin, Trilium and Logseq 2.0:** MCP servers built into the apps, off by default.
- **AFFiNE:** MCP on its cloud and self-hosted servers when AI is on.
- **Vikunja:** a built-in MCP server is on the main branch, not yet in a stable release.
- **Super Productivity, Kimai, solidtime and WeKan:** community MCP servers built by other people.

Here is what that looks like in Open Sunsama. You ask your agent to plan the afternoon. The tasks and time blocks appear on your calendar as it works.

The code is public, too. So your agent can read how the planner works and even help you change it. For more options, see our list of [task managers with MCP](/blog/best-task-managers-with-mcp).

## Should you self-host or use the cloud?

Self-host when you want full control, when rules like GDPR keep your data in one place, or when you already run a home server. You own the updates and the backups.

Use a hosted version when you want to start today and never think about servers. Many apps here, including Open Sunsama, Vikunja and tududi, run the same code in both places, so you can move later.

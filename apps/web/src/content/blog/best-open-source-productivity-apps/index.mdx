## How we compared these apps

We build Open Sunsama and use it to plan our own days. For every other app, we read the license file, the release notes and the docs for sync, API and MCP. We also read what users say on Reddit, Hacker News and GitHub.

We did not run every app for weeks, so we don't claim to have tested them. An app made the list only if it had a release in 2026, because self-hosters ask "seems no longer maintained?" about every project.

## What counts as open source?

Open source means the code is public and the license lets you use, change and share it. Not every public repo meets that bar. The license tells you what you can really do.

| License | Self-host | Change and share | Commercial use |
|---|---|---|---|
| **MIT, Apache 2.0** | Yes | Yes | Yes |
| **GPL-3.0, AGPL-3.0** | Yes | Yes, but share your changes | Yes |
| **Non-commercial (Open Sunsama)** | Yes, for personal use | Personal use | Needs a commercial license |
| **Proprietary (Obsidian)** | Local files only | No | Yes, free since 2025 |

Here is Open Sunsama's license in plain words. The code is public on GitHub, and you can read it, run it and self-host it for personal use. Companies need a commercial license.

That is not an OSI license. If your company needs MIT or GPL, pick Super Productivity for planning and Vikunja or Tududi for tasks.

What it does well:

- [Time blocking](/features/time-blocking) in day and week views.
- Rollover, recurring tasks and reminders.
- Planned vs actual: the focus timer tracks the time you really spent.
- Subtasks, notes, file attachments and priorities P0 to P3.
- Keyboard first, with a command palette on Cmd+K.
- Web, desktop for Mac, Windows and Linux, and a mobile web app for your phone.
- A public REST API with API keys, plus a hosted MCP server.

Where it falls short:

- The license is non-commercial, not MIT or GPL.
- It is young. The first commit was in January 2026.
- It plans one person's day. It is not a team project tool.

**Pick it if** you want to plan your day with time blocks and let an AI agent do the busywork. Self-host it with the [Docker guide](/docs/self-hosting/docker), or [download the apps](/download).

### Super Productivity: offline-first tasks and timeboxing

**Verdict:** the best MIT-licensed planner for one person who wants no server at all.

**Best for:** developers who track time against GitHub, GitLab or Jira issues.

What it does well:

- Apps for Linux, macOS, Windows, Android and iOS.
- Timeboxing, a focus timer and time tracking in one app.
- Works offline with no account. Syncs through WebDAV, Dropbox or SuperSync.
- Pulls in issues from GitHub, GitLab, Jira and more.

Where it falls short:

- Built for one person, not a shared team server.
- MCP comes from community plugins, not the core app.

**Pick it if** you want an MIT app that works offline and tracks your time.

Open Sunsama is our pick, and Super Productivity is the best MIT option. They solve the problem in different ways.

## Task management apps

### Vikunja: the closest thing to a self-hosted Todoist

**Verdict:** the safest self-hosted task manager for people coming from Todoist.

**Best for:** individuals and small teams who want lists, kanban, Gantt and table views.

- **Good:** Todoist importer, CalDAV, reminders, a REST API and a Docker image.
- **Falls short:** no stable native phone app yet, and no official MCP server.
- **Pick it if** you want Todoist's workflow on your own server.

### Tududi: small, calm and AI-ready

**Verdict:** the lightest self-hosted task app, with an MCP server built in.

**Best for:** home-labbers who want areas, projects, tasks and notes in one small container.

- **Good:** one Docker command, a single SQLite file, CalDAV, OIDC login, a Telegram bot and 59 MCP tools.
- **Falls short:** web app only on phones, and no calendar view for time blocking.
- **Pick it if** you want a simple task list your AI agent can use today.

### Kanboard: minimal kanban that keeps working

**Verdict:** a fast, tiny kanban board that has run for over a decade.

**Best for:** people who want kanban and nothing else.

- **Good:** swimlanes, automatic actions, plugins, and it runs on almost any PHP host.
- **Falls short:** the project says it is in maintenance mode, so expect fixes, not new features.
- **Pick it if** you want a stable board you set up once and forget.

### WeKan: an open source Trello

**Verdict:** the most complete Trello-style board you can self-host.

**Best for:** teams moving off Trello.

- **Good:** boards, lists, cards, checklists, custom fields, rules and LDAP login.
- **Falls short:** it can feel heavy for one person's to-do list.
- **Pick it if** your team already thinks in Trello boards.

## Note-taking apps

### Joplin: private notes on every device

**Verdict:** the best open source notes app if you want real phone apps and your own sync.

**Best for:** people who want Markdown notes and to-dos, synced through storage they own.

- **Good:** apps on every platform, end-to-end encryption, sync through Joplin Server, Nextcloud, WebDAV or Dropbox, and a local MCP server in the desktop app.
- **Falls short:** Joplin Server uses a separate personal-use license, and tasks are just notes with checkboxes.
- **Pick it if** you want one private app for notes and simple to-dos.

### Logseq: an outliner with linked notes

**Verdict:** great for research and linked thinking, but in the middle of a big change.

**Best for:** people who think in outlines and backlinks.

- **Good:** block links, a graph view, PDF notes and flashcards.
- **Falls short:** Logseq 2.0 is a beta that moves notes into a database. The older 0.10 version keeps plain Markdown files.
- **Pick it if** you want an outliner and are fine with a beta or the older file version.

### Trilium Notes: a deep note tree you host

**Verdict:** a personal wiki for people with thousands of notes.

**Best for:** people who want a self-hosted note tree with scripting.

- **Good:** a web server you host, per-note encryption and a REST API. The TriliumNext community keeps it moving.
- **Falls short:** no native phone app; you use the web version.
- **Pick it if** you want a big private knowledge base on your own server.

A note on Obsidian: it stores notes as local Markdown files and has been free for work since 2025. But its code is not open source, so we did not list it.

## Time tracking apps

### Kimai: time tracking with invoices

**Verdict:** the most complete open source time tracker for billable work.

**Best for:** freelancers, agencies and consultants.

- **Good:** projects, rates, expenses, invoices, a JSON API and many users.
- **Falls short:** more than you need to time one person's day.
- **Pick it if** you bill clients by the hour.

### Traggo: simple time tracking by tag

**Verdict:** a small time tracker with no project setup.

**Best for:** people who just want to see where their time goes.

- **Good:** tag-based entries, a calendar view, dashboards and Docker.
- **Falls short:** slower releases than the other apps here. The last one was in March 2026.
- **Pick it if** you want the lightest possible time log.

## Calendar apps

### Nextcloud Calendar: a calendar inside your Nextcloud

**Verdict:** the easiest self-hosted calendar if you already run Nextcloud.

**Best for:** Nextcloud users.

- **Good:** CalDAV sync with any calendar app, shared calendars and room booking.
- **Falls short:** you need the whole Nextcloud server.
- **Pick it if** Nextcloud is already your home for files and contacts.

### Radicale: a tiny CalDAV server

**Verdict:** the lightest way to host your own calendar and contacts.

**Best for:** people who only need a sync server for their phone and desktop apps.

- **Good:** small, simple to run, and it works with Tasks.org, Thunderbird and Apple apps.
- **Falls short:** no full web calendar. You use other apps to see your events.
- **Pick it if** you want your calendar off Google with the least work.

## Which open source productivity apps work with AI agents?

MCP is the plug that lets an AI agent read and change your tasks. In 2026 it matters as much as an API.

- **Open Sunsama:** a hosted MCP server with OAuth sign-in and 24 tools. It works in Claude, ChatGPT, Cursor and any MCP client, and it reads your synced meetings too. See the [MCP setup guide](/docs/mcp/overview).
- **Tududi:** an MCP server in every instance, using a personal token.
- **Joplin:** a local MCP server in the desktop app, off by default.
- **Vikunja and Super Productivity:** community MCP servers and plugins.

Here is what that looks like in Open Sunsama. You ask your agent to plan the afternoon. The tasks and time blocks appear on your calendar as it works.

## Should you self-host or use the cloud?

Self-host when you want full control, when rules like GDPR keep your data in one place, or when you already run a home server. You own the updates and the backups.

Use a hosted version when you want to start today and never think about servers. Many apps here, including Open Sunsama, Vikunja and Tududi, run the same code in both places, so you can move later.

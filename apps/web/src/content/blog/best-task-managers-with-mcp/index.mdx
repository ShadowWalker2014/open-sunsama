The best task manager with MCP in 2026 is **Open Sunsama**. It is an open-source daily planner with time blocking that works with any AI agent. Your data stays yours: you can self-host it, and it has a public API.

Todoist, Sunsama, TickTick and Akiflow also run official, hosted MCP servers with OAuth sign-in. Pick Todoist for a plain, fast to-do list. Pick Sunsama or Akiflow if you want a daily planner that pulls in work from many other tools.

- **Best for a simple to-do list:** [Todoist](https://www.todoist.com). Official server at `ai.todoist.net/mcp`, works on its Beginner plan.

- **Best for team work:** Linear, Asana and Notion all run official servers.
- **No official server yet:** Things 3, Motion and Microsoft To Do. Only community-built servers exist.

## What can an AI do with a task manager MCP?

MCP (Model Context Protocol) is an open standard. It gives an AI app a set of tools, like "list tasks" or "create task". You connect once, and then you just talk.

With a good server, you can say "plan my day" or "move everything I didn't finish to tomorrow". The AI reads your tasks, makes the changes and tells you what it did. The better servers also let it see your calendar, so the plan fits around your meetings.

Most servers here use OAuth. You sign in on the app's own page, and the AI gets a token, never your password. You can cut off access from either side at any time.

## 2. Todoist: best for a simple to-do list

**Verdict:** the easiest way to give Claude or ChatGPT a to-do list, if you don't need time blocks.

**Best for:** people who live in lists and want an AI to add, sort and clear tasks.

**What it does well:** Todoist runs its own hosted server at `https://ai.todoist.net/mcp`. Its [help page](https://www.todoist.com/help/todoist/todoist-and-ai/connect-todoist-to-an-ai-assistant-xMSzFfHng) has setup guides for Claude, Claude Code, ChatGPT, Codex and Gemini Spark. The server works on the Beginner, Pro and Business plans.

The AI can create tasks and projects, edit them and complete them. It can also read your activity log, so "what did I finish yesterday?" works. The server code is open source on [GitHub](https://github.com/Doist/todoist-mcp).

**Where it falls short:** Todoist is a list app first, so your meetings live somewhere else. Many people add a calendar connector next to it so the AI can see their day. Some Reddit users say they had to sign in again and again, and Todoist's own help page lists this as a known issue.

**Pick it if** you want the most tested to-do MCP and you plan in lists, not by the hour.

## 3. Sunsama: best for a guided daily planner with integrations

**Verdict:** a strong official MCP for people who already love Sunsama's daily planning ritual.

**Best for:** Sunsama users who want Claude or ChatGPT to work with their existing board.

**What it does well:** Sunsama runs a hosted server at `https://api.sunsama.com/mcp` with OAuth. It is in ChatGPT's plugin directory, so you can add it without developer mode. Its [help page](https://help.sunsama.com/docs/mcp-model-context-protocol) also covers Claude, Claude Desktop, Cursor, Claude Code and Notion agents.

The server left beta in August 2026. Since then Sunsama has added tools to edit task notes, manage channels and read and post comments.

Changes made over MCP now sync back to Todoist, Asana, ClickUp, Notion, Trello and Gmail. Sunsama also has its own built-in AI assistant, Sunny.

**Where it falls short:** Sunsama has no public REST API. The API request on its roadmap has been open since December 2019.

In April 2026 a Claude user found the MCP did not share actual tracked time, and Sunsama said that was coming. MCP is part of the Pro plan: $17 a month billed yearly, or $22 monthly (checked September 2026).

**Pick it if** you already pay for Sunsama and want your AI to join in. For the full setup, read our [Sunsama MCP guide](/blog/sunsama-mcp).

## 4. TickTick: best for tasks plus habits and focus stats

**Verdict:** a wide official server that reaches parts of TickTick its API never did.

**Best for:** TickTick users who track habits and Pomodoro sessions next to their tasks.

**What it does well:** TickTick hosts its server at `https://mcp.ticktick.com`. You sign in with OAuth, or paste an API token from your TickTick settings. Beyond tasks and lists, the AI can check in habits and read your focus records and countdowns.

**Where it falls short:** It only speaks Streamable HTTP, so older clients that need SSE can't connect. It covers the basics, not every view: filters, smart lists and sharing are out of reach.

**Pick it if** TickTick is already your home for tasks and habits.

## 5. Akiflow: best for many calendars and meeting notes

**Verdict:** a strong pick for people who live in meetings.

**Best for:** busy people with several calendars who want the AI to turn meeting notes into scheduled work.

**What it does well:** Akiflow's [MCP page](https://akiflow.com/mcp) lists 19 actions at `mcp.akiflow.com/mcp`. They cover tasks, calendar events, time slots, your schedule and meeting transcripts. So "pull the action items from my product sync and schedule them this week" is one request.

**Where it falls short:** Akiflow is a paid app built around one inbox for all your tools. That is a lot of setup if you only want a light to-do list.

**Pick it if** your day is mostly meetings and follow-ups across many calendars.

## Team tools with official servers: Linear, Asana and Notion

These are not personal planners, but many people keep tasks in them. All three have solid official servers.

- **[Linear](https://linear.app/docs/mcp):** `https://mcp.linear.app/mcp` for issues, projects and comments. It also has a `/mcp/readonly` address if you only want the AI to look.
- **[Asana](https://developers.asana.com/docs/using-asanas-mcp-server):** `https://mcp.asana.com/v2/mcp`. Asana also has its own apps inside Claude and ChatGPT.
- **Notion:** `https://mcp.notion.com/mcp` for pages and databases. The hosted server uses OAuth only, so a person has to sign in.

## Calendar servers: Google Calendar and Reclaim

A to-do list tells the AI what to do. A calendar tells it when you are free. For a real plan, it needs both.

Google offers an official [Calendar MCP server](https://developers.google.com/workspace/calendar/api/guides/configure-mcp-server), but it is a developer preview. You need to join the preview, make a Google Cloud project and create your own OAuth client. That is a lot of setup for most people.

[Reclaim](https://reclaim.ai/integrations/claude), now part of Dropbox, has a hosted server at `https://mcp.reclaim.ai`. Any change your AI wants to make to your calendar shows up in a preview for you to approve first. It works on calendar events, not a task list.

## Apps with no official MCP server yet

**Things 3:** Cultured Code says Things has no direct link to Claude or ChatGPT. Its [support page](https://culturedcode.com/things/support/articles/5510170/) warns that some third-party tools can corrupt your database. It lists the safe methods to look for: the URL scheme, Shortcuts, AppleScript and Mail to Things.

**Motion:** We found only community-built servers for Motion's planner. The ones we found use a personal API key and run on your own computer, so claude.ai on the web can't reach them.

**Microsoft To Do:** We found only community projects that use the Microsoft Graph API. Check the code before you give one write access.

## How to connect a task manager to Claude or ChatGPT

The steps are almost the same for every server on this list.

1. **Copy the server URL** from the table above.
2. **In Claude:** open Settings → Customize → Connectors, click **Add custom connector**, paste the URL and click **Connect**. Custom connectors work on every Claude plan, and the Free plan allows one.
3. **In ChatGPT:** look for the app in ChatGPT's plugin directory first. If it is not there, turn on developer mode (paid plans) and add the URL as a new plugin.
4. **In Claude Code:** run `claude mcp add --transport http <name> <url>`, then type `/mcp` to sign in.
5. **Sign in** on the app's own page and approve access.
6. **Test with a read-only prompt** such as "What's on my list today?" before you let it write.

Open Sunsama runs a hosted [Model Context Protocol](https://modelcontextprotocol.io) (MCP) server. Add one URL to your AI assistant, sign in, and it can read and plan your day: tasks, subtasks, and calendar time blocks.

## Connect in one step

Paste this connector URL into your AI assistant:

```
https://api.opensunsama.com/mcp
```

Your assistant opens an Open Sunsama sign-in page. You approve access, and you're connected. There's no API key to create, copy, or rotate.

| Assistant | How to add it | Guide |
| --- | --- | --- |
| **Claude** (claude.ai, Desktop, mobile) | Settings → Customize → Connectors → Add | [Claude setup](/docs/mcp/claude) |
| **ChatGPT** | Turn on Developer mode, then Plugins → **+** | [ChatGPT setup](/docs/mcp/chatgpt) |
| **Claude Code** | `claude mcp add --transport http open-sunsama https://api.opensunsama.com/mcp` | [Claude setup](/docs/mcp/claude#claude-code) |
| **Cursor** | One-click install, or add the URL to `mcp.json` | [Cursor setup](/docs/mcp/cursor) |
| **VS Code** | Add the URL as an `http` server in `.vscode/mcp.json` | [Local & other clients](/docs/mcp/local-server#vs-code) |
| **Any other MCP client** | Add the URL as a Streamable HTTP server with OAuth | [Local & other clients](/docs/mcp/local-server) |

The quickest way to get these steps is in the app. Go to **Settings → MCP**, where the URL and instructions for each assistant are ready to copy.

## What your assistant can do

Once connected, ask in plain language:

```
"What's on my plate today?"

"Create a P1 task to review the Q3 roadmap for Thursday, 45 minutes."

"Block 9–11am tomorrow for deep work on the launch plan and link it to that task."

"Move everything I didn't finish today to tomorrow."

"Add subtasks to 'Launch feature': write tests, update docs, deploy to staging."
```

## How sign-in works

The connector uses OAuth 2.1, the same standard as "Sign in with Google". Here's what happens when you click **Connect**:

1. Your assistant registers itself with Open Sunsama and sends you to our consent screen.
2. You sign in (or create an account). The screen shows which app is asking and what it can access.
3. You click **Allow access**. The assistant gets a short-lived token scoped to your account only.

The assistant never sees your password. Access tokens expire after an hour and refresh automatically. You can disconnect any app at any time in **Settings → MCP → Connected apps**, which revokes its access immediately.

Technical details for client developers:

- Streamable HTTP transport at `https://api.opensunsama.com/mcp` (stateless, JSON responses).
- Protected resource metadata at `/.well-known/oauth-protected-resource` (RFC 9728) and authorization server metadata at `/.well-known/oauth-authorization-server` (RFC 8414).
- Authorization code flow with PKCE (S256). Clients register with Client ID Metadata Documents or dynamic client registration (RFC 7591).
- Refresh tokens rotate on every use. The authorization response carries `iss` (RFC 9207). Tokens are bound to the `/mcp` resource (RFC 8707).

## Available tools

The server provides 23 tools. Each is annotated as read-only or destructive, so your assistant can ask before it deletes anything.

### Tasks

| Tool | Description |
| --- | --- |
| `list_tasks` | List tasks by date, date range, backlog, or completion |
| `get_task` | Get a task by ID |
| `create_task` | Create a task (title, notes, date, priority, estimate) |
| `update_task` | Update task details |
| `complete_task` / `uncomplete_task` | Mark a task done or reopen it |
| `delete_task` | Delete a task |
| `schedule_task` | Move a task to a date or the backlog |
| `reorder_tasks` | Change task order within a day |

### Time blocks

| Tool | Description |
| --- | --- |
| `list_time_blocks` | List time blocks by date, range, or task |
| `get_time_block` | Get a time block by ID |
| `create_time_block` | Create a calendar block |
| `update_time_block` | Move or resize a block |
| `delete_time_block` | Delete a block |
| `link_task_to_time_block` | Put a task on the calendar |
| `get_schedule_for_day` | See a whole day's tasks and blocks at once |

### Subtasks

| Tool | Description |
| --- | --- |
| `list_subtasks` | List a task's subtasks |
| `create_subtask` | Add a subtask |
| `toggle_subtask` | Check or uncheck a subtask |
| `update_subtask` | Rename or reorder a subtask |
| `delete_subtask` | Delete a subtask |

### Profile

| Tool | Description |
| --- | --- |
| `get_user_profile` | Your name, email, and timezone |
| `update_user_profile` | Update your name or timezone |

## Prefer an API key?

The local command-line server (`npx @open-sunsama/mcp`) and API-key access still work. Use them for clients that can't do OAuth, scripts, or self-hosted setups. See [Local server & API keys](/docs/mcp/local-server).

## Troubleshooting

- **"Couldn't reach the MCP server"**: check that the URL is exactly `https://api.opensunsama.com/mcp`, with no trailing slash and nothing after `/mcp`.
- **The sign-in page says the link expired**: the consent link is valid for 15 minutes. Click **Connect** in your assistant again.
- **The assistant stopped working after a while**: open **Settings → MCP → Connected apps**. If the app isn't listed, reconnect it from your assistant.
- **Self-hosting?** Replace the host with your own API URL, for example `https://api.your-domain.com/mcp`, and set `API_URL` and `WEB_APP_URL` on the API service.

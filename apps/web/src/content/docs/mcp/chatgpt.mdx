ChatGPT connects to Open Sunsama through its developer mode, which can add any remote MCP server as an app. You sign in once with Open Sunsama, and no API key is involved.

Developer mode is available on paid ChatGPT plans (Plus, Pro, Business, Enterprise, and Edu). On Business and Enterprise workspaces, an admin may need to allow it.

## Add Open Sunsama to ChatGPT

1. In ChatGPT, open **Settings → Apps** (called **Apps & Connectors** in some versions).
2. Under **Advanced settings**, turn on **Developer mode**.
3. Click **Create app** (or **Create** next to the app list).
4. Fill in the form:
   - **Name:** Open Sunsama
   - **Description:** My tasks, subtasks, and calendar time blocks
   - **MCP server URL:**

     ```
     https://api.opensunsama.com/mcp
     ```

   - **Authentication:** OAuth
5. Click **Create**. ChatGPT opens the Open Sunsama sign-in page.
6. Sign in and click **Allow access**. ChatGPT shows the Open Sunsama tools it found.

## Use it in a chat

Start a new chat, click **+** in the message box, and pick **Open Sunsama** from the apps in developer mode. Then ask, for example:

```
"Plan my afternoon: list today's open tasks and block time for the top two."
```

ChatGPT asks you to confirm before it runs a tool that changes your data. Read-only tools, such as listing tasks, run without a prompt.

## Disconnecting

Delete the app in ChatGPT's **Settings → Apps**, or open **Open Sunsama → Settings → MCP → Connected apps** and click **Disconnect** next to ChatGPT. Access stops immediately.

## Troubleshooting

- **The sign-in page never opens**: make sure **Authentication** is set to **OAuth**, and that the URL ends in `/mcp`.
- **"Developer mode" is missing**: your plan or workspace doesn't allow it yet. Ask your workspace admin.
- **Tools stopped working**: open the app in ChatGPT settings and reconnect it.

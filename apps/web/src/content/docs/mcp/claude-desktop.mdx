Claude Desktop uses the same connectors as claude.ai. If you've already added Open Sunsama on the web, it's available in the Desktop app too. There's nothing to install and no config file to edit.

## Recommended: add the connector

1. In Claude Desktop, open **Settings → Customize → Connectors** and click **Add**.
2. Enter the name **Open Sunsama** and this MCP server URL:

   ```
   https://api.opensunsama.com/mcp
   ```

3. Click **Continue**, keep the detected sign-in settings, and click **Add**. Then click **Connect**, sign in to Open Sunsama, and click **Allow access**.

The full walkthrough, including Team and Enterprise plans, is in [Claude setup](/docs/mcp/claude).

## Alternative: local server with an API key

Use this if your organization blocks custom connectors, or if you point Claude Desktop at a self-hosted instance that isn't reachable from the internet.

1. In Open Sunsama, open **Settings → MCP**, expand **Use an API key instead**, and click **Generate key**.
2. In Claude Desktop, open **Settings → Developer → Edit Config**. This opens `claude_desktop_config.json`:
   - macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
   - Windows: `%APPDATA%\Claude\claude_desktop_config.json`
3. Add the server:

   ```json
   {
     "mcpServers": {
       "open-sunsama": {
         "command": "npx",
         "args": ["-y", "@open-sunsama/mcp"],
         "env": {
           "OPENSUNSAMA_API_KEY": "os_your_key_here"
         }
       }
     }
   }
   ```

   For a self-hosted instance, add `"OPENSUNSAMA_API_URL": "https://api.your-domain.com"` to `env`.
4. Quit and reopen Claude Desktop.

The local server needs Node.js 18 or newer. To check it outside Claude, run `OPENSUNSAMA_API_KEY=os_your_key npx @open-sunsama/mcp`. It should print `Open Sunsama MCP Server running on stdio`.

Logs are at `~/Library/Logs/Claude/mcp-server-open-sunsama.log` on macOS and `%APPDATA%\Claude\logs\mcp-server-open-sunsama.log` on Windows.

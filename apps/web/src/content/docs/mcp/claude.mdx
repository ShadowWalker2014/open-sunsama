Add Open Sunsama to Claude once and it works everywhere you use Claude: claude.ai, Claude Desktop, the iOS and Android apps, and Cowork. Custom connectors are available on every Claude plan. The Free plan allows one custom connector.

## Claude (web, Desktop, and mobile)

1. In Claude, open **Settings → Customize → Connectors** ([direct link](https://claude.ai/new#customize/connectors)).
2. Click **Add**. The **Add custom connector** dialog opens.
3. Enter the name **Open Sunsama** and this **MCP server URL**:

   ```
   https://api.opensunsama.com/mcp
   ```

4. Click **Continue**. Claude detects how Open Sunsama signs in and pre-selects **Sign in now** and **Use Claude's published identity**. Keep both, since you don't need a client ID or secret, and click **Add**.
5. Click **Connect**, sign in to Open Sunsama, and click **Allow access**. Claude takes you back and shows **Connected to Open Sunsama**.

New connectors are on in every chat. Ask, for example, *"What's on my schedule today?"* Claude asks before each tool call. To skip the prompt for lookups, open the connector and set **Read-only tools** to **Always allow**. You can turn the connector off for a chat under **+** → **Connectors**.

### Team and Enterprise plans

An organization owner adds the connector first. In **Organization settings → Connectors**, click **Add**, choose **Custom → Web**, and enter the URL above. Each member then opens **Settings → Customize → Connectors**, finds Open Sunsama, and clicks **Connect** to sign in with their own Open Sunsama account.

## Claude Code

Run this in your terminal:

```bash
claude mcp add --transport http open-sunsama https://api.opensunsama.com/mcp
```

Start Claude Code, run `/mcp`, select **open-sunsama**, and choose **Authenticate**. Your browser opens the Open Sunsama consent screen. After you allow access, the tools are available in every session.

Add `--scope user` to make the server available in all your projects, not just the current one.

## Permissions and disconnecting

Claude can view and edit your tasks, subtasks, and time blocks, and read your profile (name, email, timezone). Tools that delete data are marked as destructive, so Claude asks before it runs them.

To disconnect, remove the connector in Claude, or open **Open Sunsama → Settings → MCP → Connected apps** and click **Disconnect**. Access stops immediately.

## Troubleshooting

- **"Couldn't reach the MCP server"**: check the URL is exactly `https://api.opensunsama.com/mcp`.
- **The connector shows as disconnected**: click **Connect** again and approve access. This happens after you disconnect it from Open Sunsama's settings.
- **Claude doesn't use the tools**: make sure the connector is on for the conversation (**+** → **Connectors**), or mention Open Sunsama in your request.
